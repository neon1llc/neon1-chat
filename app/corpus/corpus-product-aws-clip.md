AWS CLI Plus: a wrapper around the AWS CLI that checks your account, explains commands and hides secrets.

*Public · pre-release*

**AWS CLI Plus.** A wrapper around the AWS CLI that checks which account you're in, explains what a command will do before it runs, and hides secrets in its output.

Code and docs: [neon1llc/aws-clip](https://github.com/neon1llc/aws-clip).
