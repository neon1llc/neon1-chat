## Live grade

| Grade | Live v0.2.9 | Baseline (v0.2.4, Nov 16 morning) |

The release gate passes. Median reply time was 3.4 seconds.

Rubric failures:

- form-to-sheet-cost: quotes the small-fix range ($150 to $750) for a form-to-spreadsheet workflow and leaves out the workflow project range.
- square-to-qbo: names Automate.io, a tool that shut down in 2022, and offers no person.

- what-is-mfa: says "neon1 requires MFA for all systems it accesses" and "it's one of the first things Pradeep does". The pages don't say either.

- file-server-cloud: misses an expected point.
- chinese-pos: says neon1 can set up a point-of-sale system, then says it doesn't install hardware. The reply also keeps first person (我可以).

Three questions passed the baseline and fail now: form-to-sheet-cost, what-is-mfa, and portal-soc2. The gate counts totals, so these swaps don't fail it.

## The voice pass

`voice.mjs` (removed in v0.2.10 with the pass; it's in commit a07448f) sent each question once and keeps two versions of the reply, one with the voice pass and one without, both built from the same model output. The judge then compared each pair that differed.

| Measure | Result |
| --- | --- |
| Replies where the pass ran | 12 of 52 (23%) |
| Rewrites used (2 rejected by the guard) | 10 |
| Added time when it runs | median 2.5 s, max 4.8 s (the answer call itself: median 2.7 s) |
| Added cost | 1.2% of model spend, about $0.0003 a triggered reply |
| Rubric, without vs with the pass | 9/10 vs 9/10; it fixed none and broke none |
| Judge's meaning check | 7 same, 3 minor, 0 changed |

The judge called three changes "minor". Two of them change meaning:

- spreadsheets-start: "You'd keep your spreadsheets" became "neon1 keeps your spreadsheets". The visitor's action became a claim about neon1.
- not-a-tech-person: the sentence "Pradeep will help you name it" was dropped, and "without us" was left as it was.
- how-much: "after we talk" became "after neon1 talks". That's awkward but means the same.

First person the pass misses: "I'd start by checking" (wifi-drops on the live run), Spanish "puedo ayudarte" (the guard rejected that rewrite), and Chinese 我可以.

Prices: Qwen3 Next 80B on Bedrock costs $0.14 per million input tokens and $1.20 per million output tokens (on-demand standard tier, us-east-1, price list effective 2026-11-01). The judge runs cost about $0.40 for the live run and about $0.25 for the voice pairs.

## Decision and result: v0.2.10

Pradeep chose to drop the voice pass. Fixed rules now handle first person in English, Spanish, French, and Chinese. Code also guards the claims that prompt rules didn't hold: unstated neon1 practices, past work that names no published case study, outcome percentages, deciding whether a law applies, incident replies without the no-emergency note, and a missing route to Pradeep on help and cost answers. The release bar is a consistent 48 to 50 of 52 on the rubric.

Graded runs on Bedrock (Qwen3 Next 80B, temperature 0.3), from the first fix to the release commit:

| Run | Keywords | Rubric |
| --- | --- | --- |
| 1 to 6, while fixing | 49 to 52 | 45, 44, 46, 45, 47, 47 |
| Trial with Claude Sonnet 4.6 as the answer model | 47 | 47 (median 3.6 s against Qwen's 3.0 s, so Qwen stays) |
| 7 | 52 | 49 |
| 8 | 52 | 48 |
| 9 | 52 | 49 |
| Held-out set (20 questions never tuned against) | 20/20 | 16/20 |

In runs 7 to 9 the judge's verdict on chinese-pos was unreadable and counted as a miss, so those totals are a floor. The held-out set scores lower (80% against 92% to 94%). Its misses are missing details (typical length, cost drivers) and one reply implying Neo can recommend repair shops. Next, those questions should get rules that aren't tuned against the held-out wording itself.
