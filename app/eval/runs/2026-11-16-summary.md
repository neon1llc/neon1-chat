## The voice pass

`voice.mjs` sends each question once and keeps two versions of the reply, one with the voice pass and one without, both built from the same model output. The judge then compares each pair that differs.

| Measure | Result |
| --- | --- |
| Replies where the pass ran | 12 of 52 (23%) |
| Rewrites used (2 rejected by the guard) | 10 |
| Added time when it runs | median 2.5 s, max 4.8 s (the answer call itself: median 2.7 s) |
| Added cost | 1.2% of model spend, about $0.0003 a triggered reply |
| Rubric, without vs with the pass | 9/10 vs 9/10; it fixed none and broke none |
| Judge's meaning check | 7 same, 3 minor, 0 changed |

The judge called three changes "minor". Two of them change meaning:

- spreadsheets-start: "You'd keep your spreadsheets" became "neon1 keeps your spreadsheets". The visitor's action became a claim about neon1.
- not-a-tech-person: the sentence "Pradeep will help you name it" was dropped, and "without us" was left as it was.
- how-much: "after we talk" became "after neon1 talks". That's awkward but means the same.

First person the pass misses: "I'd start by checking" (wifi-drops on the live run), Spanish "puedo ayudarte" (the guard rejected that rewrite), and Chinese 我可以.

Prices: Qwen3 Next 80B on Bedrock costs $0.14 per million input tokens and $1.20 per million output tokens (on-demand standard tier, us-east-1, price list effective 2026-11-01). The judge runs cost about $0.40 for the live run and about $0.25 for the voice pairs.
